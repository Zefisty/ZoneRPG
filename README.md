# ZoneRPG

Статическая браузерная 2D RPG в духе STALKER. Игра работает на Canvas и обычных JavaScript-файлах: сборка, серверная часть, внешние библиотеки и платные ресурсы не нужны.

## Запуск

Откройте `index.html` в современном браузере или опубликуйте эту папку на GitHub Pages. Для локальной проверки можно запустить `python -m http.server` из папки проекта.

## Управление

- **WASD / стрелки** — движение.
- **E** — взаимодействовать с объектом рядом.
- **ЛКМ** — выстрелить в направлении указателя.
- **R** — перезарядить оружие.
- **1–3** — выбрать имеющееся оружие.
- **I** — рюкзак; **J** — журнал; **Esc** — пауза.

Прогресс сохраняется в `localStorage` текущего браузера. Разные браузеры и устройства используют отдельные сохранения.
