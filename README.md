# ZONE RPG

Небольшая статическая браузерная игра-бродилка по Зоне. Персонаж путешествует по сети секторов, выбирает маршрут и решает, как реагировать на встречи. Данные мира и предметов отделены от интерфейса, состояния, сохранения и игрового движка.

## Запуск

Откройте `index.html` в современном браузере или разместите папку на GitHub Pages. Сборка, серверная часть, сетевые запросы и внешние библиотеки не нужны.

## Управление

- **Карта** — доступные соседние секторы и опасность маршрутов.
- **Исследовать** — продолжайте вылазку, пока хватает выносливости; глубина исследования сохраняется между событиями.
- **КПК** — рюкзак, задания, карта, персонаж и настройки.
- **Esc** — пауза; на телефоне используйте экранные кнопки.
- В бою выберите действие кнопкой: прицел, атака, перезарядка, предмет, смена оружия или отход.

Сохранение использует версионированный `localStorage` этого браузера. Для продолжения используйте кнопку «Продолжить вылазку» на стартовом экране.

## Патч 6.1.1

Шесть стартовых предысторий, бесплатная передышка в обычном секторе, продолжения осмотров, сдача поручений через заказчиков и журнал, читаемая карта и уточнённые боевые изображения. Схема сохранений 7 автоматически переносит старые данные без повторного начисления стартовых бонусов.

«Передохнуть · 1 час» восстанавливает 25 выносливости и увеличивает голод/жажду; костёр за 35 ₽ по-прежнему даёт лучший отдых. Набор инструментов используется многократно в отмеченных действиях событий.
