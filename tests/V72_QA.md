# ZoneRPG v7.2 — проверки и состояние работы

Дата: 2026-10-10. Изменения оставлены в рабочем дереве; commit/push не выполнялись.

## Реализовано

- Бандит — отдельный мирный NPC-свинья на Военном блокпосту с оригинальным локальным SVG, историей, кормлением и поглаживанием. Забота ограничена мировым временем, бинт выдаётся один раз.
- Все шесть предысторий доступны; у Новичка два свободных очка, антирад и нейтральные стартовые отношения с одиночками, бандитами и военными. У остальных различаются вещи, пассивные бонусы и вступительные встречи.
- Послебоевые действия дают дополнительные патроны, опыт, сведения или детали. Победа и уже выбранное действие сохраняются; отступление не даёт победную добычу.
- Последние три события временно исключаются из выбора; при отсутствии альтернатив разрешён повтор.
- Застрявший люк с инструментами даёт АПС и 24 патрона 9×18 один раз. При полном рюкзаке награда и флаг не теряются. Инструменты остаются.
- Нож отображается как ближнее оружие без магазина, резерва и перезарядки. У секача убрана инструкция про паузу.
- Неудачный платный отдых не меняет здоровье, выносливость, деньги, время и прогресс. Бесплатная передышка остаётся отдельным действием.
- Аномальные поручения продвигаются действиями у аномалий, а не общим исследованием. Для полевых документов на Янтаре есть направленный поиск: находка не позднее третьей попытки при наличии места; попытки сохраняются.
- Все 55 заданий по умолчанию сдаются вручную у заказчика. Готовность не выдаёт награду. Настройка автоматической сдачи выключена по умолчанию и действует только для допустимых простых заданий у заказчика.
- В интерфейсе разделены отношение фракции к игроку и отношения между фракциями. Нижняя панель компактнее; кнопки «Ещё» сохранили размер 48 px.
- Версия схемы сохранения: 10. Старые вещи, деньги, события и задания сохраняются. Ошибочно накопленный прогресс незавершённых аномальных поручений из схемы 9 сбрасывается.

## Автоматические проверки

Команды из корня проекта:

```powershell
node tests/regressions.cjs
node tests/polish.cjs
node tests/world-logic.cjs
node tests/expedition.cjs
node tests/navigation.cjs
node tests/audio.cjs
node tests/quality-v72.cjs
node tests/audit-v72.cjs
Get-ChildItem -Recurse -File -Include *.js,*.cjs | ForEach-Object { node --check $_.FullName }
git diff --check
```

Пройдено: 13 regression, 18 polish, 27 world logic, 20 expedition, 6 navigation, 1 audio и 22 quality v7.2 = 107 групп проверок. Внутри них проверены все 55 заданий, 795 стадий событий, 90 направленных маршрутов, 316 новых вариантов v7, все типы врагов и локальные ресурсы, 50 последовательных встреч и отдельная серия из 20 встреч без повторов последних трёх ID. Аудио проверено с mock Web Audio, не прослушиванием.

Полный список заданий: [QUEST_AUDIT_V72.md](QUEST_AUDIT_V72.md).

## Обязательная браузерная проверка — НЕ выполнена

Встроенный браузер получает ERR_CONNECTION_TIMED_OUT на локальном сервере, запущенном через инструмент команд. Это не проверка игры. Нет подтверждения чистой DevTools Console, скриншотов или адаптивности текущей сборки. Патч не считается полностью завершённым до браузерного QA.

Сервер для запуска из обычного терминала пользователя:

```powershell
node tests/server.cjs
```

Адрес: http://127.0.0.1:41736/

Изолированные сценарии используют sessionStorage, не заменяют основное сохранение:

| tests/browser.html?scenario=v72-pig | Люди → Бандит, кормление, поглаживание, история, бинт один раз |

На desktop и mobile portrait/landscape проверить нижнюю навигацию, «Ещё», фракции, длинные тексты и отсутствие горизонтального скролла. Проверить error/unhandledrejection в диагностике сценариев и настоящую DevTools Console. После загрузки проверить нож, готовые задания и попытки поиска.
