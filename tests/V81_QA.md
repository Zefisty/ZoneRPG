# ZoneRPG v8.1 — слухи и записи КПК

## Изменения

- `knowledge.js` — единый реестр отображения слухов и ключей знаний. Известные ключи получают русские названия и описания; неизвестные записи показывают безопасный текст и один warning на ключ.
- Все пути получения слухов используют общий механизм: один новый слух и 8 XP за посещение мировой локации. Повторное действие и исчерпание пула объясняются без награды.
- История общих слухов едина для всех локаций: один и тот же текст не становится новой наградой после путешествия.
- `rumorVisit` сбрасывается только при прибытии в другую мировую локацию. Панели, отдых, начало/возврат экспедиции и изменение счётчика переходов его не сбрасывают.
- Старые маркеры знаний остаются в состоянии для условий событий; UI отображает их через реестр.
- Схема сохранения 12 принимает версии 2–11. Старые текстовые записи и известные ID преобразуются без наград; при отсутствии visit state используется `heard: false`, известные слухи остаются в глобальной истории.
- Архив слухов больше не обрезается до последних 30 записей.
- Кнопка «Послушать слухи» использует `secondary-button` и остаётся активной после использования.

## Браузер — пока не проверен

Попытка открыть локальный сервер в настоящем встроенном браузере завершилась `ERR_CONNECTION_TIMED_OUT` на порту 41736; ранее использовавшийся порт 41735 вернул `ERR_CONNECTION_REFUSED`. Поэтому визуальное совпадение размеров/отступов кнопок и чистота настоящей Browser Console не подтверждены.

Для проверки из обычного терминала Windows в корне проекта:

```powershell
node tests/server.cjs
```

Открыть `http://127.0.0.1:41736/tests/browser.html?scenario=v81-rumors`. Сценарий использует отдельное sessionStorage и не меняет обычное сохранение. Нажать «Загрузить», получить слух, открыть справочник и заметки, повторить действие, перейти на Свалку и обратно. Проверить сохранение/перезагрузку, возврат из вылазки, кнопку на узком экране и Console. Раздел «Диагностика теста» показывает перехваченные ошибки/warnings.

Commit и push не выполнялись.
