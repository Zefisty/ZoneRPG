# Проверки ZoneRPG

Из корня проекта:

- `node tests/regressions.cjs` — 13 регрессионных проверок.
- `node tests/polish.cjs` — 18 проверок патча, включая 24 полных осмотра, 49 входов в бой, 646 этапов с проверкой ресурсов, 23 определения квестов и все 21 локацию.
- `node tests/server.cjs` — локальная тестовая страница на http://127.0.0.1:41736/tests/browser.html.
- `tests/enemies.html` — визуальная галерея всех противников из реальных определений мира.

Сценарии браузера используют настоящие модули и обычные кнопки. Сохранения изолированы в sessionStorage; localStorage основной игры не изменяется. Ошибки JavaScript, ресурсов и предупреждения видны в раскрываемой диагностике. Детерминированный случайный выбор применяется только на тестовой странице.

`index.html` не загружает тестовые сценарии. Сервер предназначен только для локальной проверки; игра остаётся статическим сайтом.
