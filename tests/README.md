# Целевые проверки ZoneRPG

Запуск: `node tests/regressions.cjs`.

Для браузерной проверки запустите любой локальный статический сервер из корня проекта и откройте `tests/browser.html`. Сценарии воспроизводят дорожное радиособытие, старое сохранение боя с неверным изображением пса и три спорные награды. Используются настоящие модули игры и обычные кнопки интерфейса. Диагностика теста собирает исключения, ошибки ресурсов и предупреждения.

Тестовые сохранения используют отдельные ключи sessionStorage. Основной localStorage игры не изменяется. Детерминированные события и диагностика присутствуют только на тестовой странице; index.html их не загружает.
