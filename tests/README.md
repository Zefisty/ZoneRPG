# Проверки ZoneRPG

Из корня проекта:

- `node tests/regressions.cjs` — 13 регрессионных проверок.
- `node tests/polish.cjs` — 18 проверок патча, включая 24 полных осмотра, 54 входов в бой, 656 этапов с проверкой ресурсов, 23 определения квестов и все 21 локацию.
- `node tests/world-logic.cjs` — 27 проверок v6.3: 74 направления дорог, сессии Continue/Return, миграция, anti-farm, предыстории, новые враги и сдача предметов.
- `node tests/server.cjs` — локальная тестовая страница на http://127.0.0.1:41736/tests/browser.html.
- `tests/enemies.html` — визуальная галерея всех противников из реальных определений мира.

Сценарии браузера используют настоящие модули и обычные кнопки. Сохранения изолированы в sessionStorage; localStorage основной игры не изменяется. Ошибки JavaScript, ресурсов и предупреждения видны в раскрываемой диагностике. Детерминированный случайный выбор применяется только на тестовой странице.

`index.html` не загружает тестовые сценарии. Сервер предназначен только для локальной проверки; игра остаётся статическим сайтом.

Результаты: [POLISH_QA.md](POLISH_QA.md).

Патч v6.3: [V63_QA.md](V63_QA.md). Сценарии: session63-warehouses, session63-darkvalley, session63-southTunnel, news63, quests63, background63, mutant63, tool63a/tool63b/tool63c. Они используют реальные движок, UI, сохранения и DOM-обработчики кнопок; только начальное состояние и случайность фиксированы для воспроизводимости.
