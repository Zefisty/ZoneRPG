# ZoneRPG 6.1.1 — bugfix/polish QA

Дата: 2026-10-05. Изменения оставлены в рабочем дереве. Commit/push не выполнялись.

## Fixed

- Софтлок: бесплатная передышка +25 выносливости за час вне активного события/боя; есть в каждом обычном секторе, работает при 0 ₽. Костёр сохраняет лучший платный отдых.
- Источник скрытых +8: поле stamina:8 у консервов. Удалено; общая функция использования применяет только объявленные эффекты. Энергетик по-прежнему даёт 35.
- Новости: результат содержит реальный слух, который сохраняется в журнале.
- Единая привязка врага: явный enemyId через бой, канонические имя/описание/характеристики/добыча/visual. Неизвестный тип не заменяется случайным бандитом.
- У человеческих врагов человеческие силуэты; военный на блокпосте имеет отдельное определение. Кабан и матёрый кабан — четвероногие.
- Все слоты показывают снятие; переключение оружия — отдельное действие. В рюкзаке блокируются выбрасывание экипированного предмета, заполненные магазины и переполненные слоты артефактов.
- Локализованы новые и старые записи характеристик/навыков; добавлены короткие подсказки по нажатию.
- Дополнительно найден в браузере отсутствующий scene-camp.svg после боя с бандитом. Выбор иллюстрации направлен на существующий abandoned-car. Номера этапов показывают продвижение, а не порядок определения веток.

## Replayability

Шесть сохранённых предысторий: новичок; бывший военный (+1 выносливость, пистолеты5, 4 патрона); технарь (+1 интеллект, инструменты); охотник (+1 восприятие, melee5, хлеб); мародёр (+1 сила, детали, −3 отношение одиночек); медик (+1 интеллект, дополнительная аптечка). Бонусы только при новом старте. В профиль и сохранение записывается backgroundId.

## Event flow

Продолжение учитывает ссылки выбора, эффектов и текущего этапа. Проверяется существование следующего этапа. У осмотров без заявленного завершения появились выбор продолжения/отметки/обхода. «Сверить следы» ведёт к подготовке, следу, тайнику и возвращению. Явные одношаговые действия и старые цепочки сохранены. Старый завершённый осмотр версии6 мигрирует в продолжение без повторной выдачи уже начисленных предметов.

## Quests

«Груз под насыпью»: принять у Юры → два исследования железной дороги → сохранить/загрузить → сдать через разговор → +430 ₽ один раз.

«Шаги в тоннеле»: Федя даёт задание и направление к контакту → подготовка → бой с псом в Южном тоннеле → продолжение → возвращение → сдача → +480 ₽ один раз. Победа вне нужного сектора не засчитывается. Также привязаны к описанным секторам «Тихий тракт» и «Складской дозор».

Журнал показывает место получения, заказчика, место сдачи, прогресс и доступность сдачи. Старые записи восстанавливают место по заказчику или показывают «неизвестно».

## Map

Разведены узлы по трём колонкам и семи рядам. Тонкие двусторонние связи, ярче дороги из текущего сектора; скрыты связи между неизвестными узлами. На телефоне читаемый список узлов и отдельные дороги от текущего сектора. Удалён прямой переход Свалка → Дикая территория; маршрут через Тёмную долину. Исправлена симметрия старой дороги и дубли NPC. Все21 сектора достижимы в графе; старое сюжетное ограничение ЧАЭС сохранено.

## Items

Набор инструментов многоразовый: генератор Агропрома, защёлка контейнера Свалки, сервисный проход в долине, люк машинного двора, электрическое соединение коллектора. Кнопки видны только с инструментами. Результат реален: информация, репутация, детали или электроника. Выдача защищена состоянием этапа, инструменты не расходуются. Старое действие в deep_cache_echo также сохраняет инструменты.
